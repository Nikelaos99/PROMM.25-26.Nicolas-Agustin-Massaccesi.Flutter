List<ProductModel> getAllProducts()

Retrieves all stored products as a synchronous List.

Since Hive keeps data in memory for fast access, this operation is efficient and provides a snapshot of the current inventory.

Implementation

List<ProductModel> getAllProducts() {
  final box = Hive.box<ProductModel>(boxName);
  return box.values.toList();
}
